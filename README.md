# TrussFrame

2D frame and truss analysis in the browser.

**Open it:** https://yewp.github.io/trussframe/

On a phone, open that address and add it to the home screen (iPhone: Share > Add to Home Screen;
Android: menu > Install app). It then opens full-screen like an app and works offline once loaded.

This repository holds only the built page (`index.html`, one self-contained file).
